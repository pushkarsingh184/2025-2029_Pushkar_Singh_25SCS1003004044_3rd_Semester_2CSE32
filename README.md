## 📌 About the Internship

The Cisco Virtual Internship Program 2026 provided practical exposure to networking concepts and applied troubleshooting. My project work focused on connecting observable network evidence with likely faults and actionable troubleshooting steps.

The capstone project, **NetSage AI**, is an AI-assisted troubleshooting helper for Cisco-style networking lab scenarios. It takes reported symptoms, topology notes and show-command evidence, then produces a structured diagnosis with the likely root cause, confidence, relevant OSI layer, next diagnostic command and evidence-backed fix steps.

The solution also includes deterministic rule checks, mandatory human review, correction history and dashboard reporting. Human oversight is retained throughout the diagnosis workflow.

---

## 🎯 Objectives

- Build a structured dataset of Cisco-style networking troubleshooting cases.
- Connect symptoms and command evidence to likely networking faults.
- Provide structured root-cause diagnosis, confidence, OSI layer, next command and fix steps.
- Implement deterministic and explainable rule checks for common networking faults.
- Maintain mandatory human review using **Accepted / Edited / Rejected** outcomes.
- Record human corrections for responsible-AI review.
- Provide dashboard and correction-history views for evaluation.
- Demonstrate a complete case → diagnosis → review → correction workflow.
