## Project Overview
NetSage AI is an AI-assisted troubleshooting helper for Cisco-style networking lab scenarios. It organizes symptoms, topology information and show-command evidence into structured cases, provides evidence-backed diagnoses and next troubleshooting steps, and includes deterministic rule checks and human review.
